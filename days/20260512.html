三、Rust vs Go: 并发模型对比

Go: CSP模型 + Goroutine

package main
import (
    "fmt"
    "time"
)

func fetchURL(url string, ch chan<- string) {
    time.Sleep(100 * time.Millisecond)
    ch <- fmt.Sprintf("Data from %s", url)
}

func main() {
    urls := []string{"api1", "api2", "api3"}
    ch := make(chan string)
    
    for _, url := range urls {
        go fetchURL(url, ch)  // 启动多个goroutine
    }
    
    for range urls {
        result := <-ch
        fmt.Println(result)
    }
}
✅ 优点
  • 语法极简，2KB初始栈
  • Channel优雅同步
  • 运行时自动调度
🟡 注意
  • 数据竞争在运行时检测
  • GC存在STW延迟

三、Rust vs Go: 并发模型对比

Rust: 所有权系统 + Async/Await

use tokio::time::{sleep, Duration};

async fn fetch_url(url: &str) -> String {
    sleep(Duration::from_millis(100)).await;
    format!("Data from {}", url)
}

#[tokio::main]
async fn main() {
    let urls = vec!["api1", "api2", "api3"];
    
    let tasks: Vec<_> = urls
        .iter()
        .map(|url| fetch_url(url))
        .collect();
    
    let results = futures::future::join_all(tasks).await;
    for result in results {
        println!("{}", result);
    }
}
✅ 优点
  • 编译期防止数据竞争
  • 无GC，性能可预测
  • Send/Sync trait保证
🟡 注意
  • 需选择运行时（Tokio）
  • 学习曲线陡峭

四、TypeScript泛型设计模式

泛型工厂模式（类型安全）

// ❌ Bad: 返回any，无类型保证
function createShape(shapeType: string) {
    if (shapeType === 'circle') return new Circle();
    return null; // 危险！
}

// ✅ Good: 泛型约束，编译期类型检查
interface Shape { draw(): void; }

class ShapeFactory {
    static createShape<T extends Shape>(ctor: new () => T): T {
        return new ctor();  // 返回类型自动推断
    }
}

const circle = ShapeFactory.createShape(Circle); // 类型Circle
✅ 审查要点
  • <T extends Shape> - 泛型约束确保类型安全
  • new () => T - 构造函数类型限制
  • 返回类型自动推断，无需手动标注

四、TypeScript泛型设计模式

泛型观察者模式（类型化事件）

interface IObserver<T> {
    update(data: T): void;
}

class Subject<T> {
    private observers: IObserver<T>[] = [];
    
    attach(observer: IObserver<T>): void {
        this.observers.push(observer);
    }
    
    notify(data: T): void {
        this.observers.forEach(obs => obs.update(data));
    }
}

const subject = new Subject<string>();
subject.attach(new Observer());
subject.notify("message");  // OK
// subject.notify(123);     // ❌ 编译错误！
类型安全: 泛型T确保update参数类型一致，编译期捕获类型错误

五、跨语言架构模式

依赖注入: TypeScript ↔ Swift

TypeScript

interface Logger {
    log(msg: string): void;
}

class Service {
    constructor(
        private logger: Logger
    ) {}
    
    doSomething() {
        this.logger.log("...");
    }
}

Swift

protocol Logger {
    func log(_ msg: String)
}

class Service {
    private let logger: Logger
    
    init(logger: Logger) {
        self.logger = logger
    }
    
    func doSomething() {
        logger.log("...")
    }
}

💡 设计启示: 接口/协议抽象解耦依赖，不同语言实现思路一致

五、跨语言架构模式

资源管理: RAII vs defer

Rust (RAII)

struct File {
    file: std::fs::File,
}

impl Drop for File {
    fn drop(&mut self) {
        // 自动关闭
    }
}

Swift/Go (defer)

// Swift
func readFile() {
    let file = FileHandle()
    defer {
        file.close()
    }
    // ... 使用file
}

// Go
func readFile() {
    file, _ := os.Open("file.txt")
    defer file.Close()
}
设计启示: 三种语言用不同机制实现RAII，核心思想一致：作用域结束时自动释放资源
