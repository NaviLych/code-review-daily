    ↓

  • Interactor: 纯业务

  • Mock轻易替换
  • 单元覆盖

反模式：React 渲染内重复计算

来源 AI生成代码典型问题

function UserList({ users }) {
  const [searchTerm, setSearchTerm] = useState('');
  const [sortField, setSortField] = useState('name');
  
  // 🔴 每次渲染都重新计算！
  const filteredUsers = users.filter(user =>
    user.name.toLowerCase().includes(searchTerm.toLowerCase())
  );
  
  // 🔴 二次遍历 + 每次创建新数组
  const sortedUsers = [...filteredUsers].sort((a, b) => { ... });
  
  return ( ... );
}

🔴 诊断：数据流问题

维度问题
输入键盘输入触发完整重算
中间状态filter+sort 双遍历
边界空数组未处理、长数组崩溃
AI隐瞒不提 useMemo、useDeferredValue

💡 性能影响：1000条数据下，每次输入触发 5-8ms 耗时，打字时帧率骤降

✅

修复：useMemo + useDeferredValue

function UserList({ users }) {
  // ✅ useMemo 缓存计算结果
  const normalizedSearchTerm = useMemo(
    () => searchTerm.toLowerCase(),
    [searchTerm]
  );
  
  const processedUsers = useMemo(() => {
    const filtered = users.filter(user =>
      user.name.toLowerCase().includes(normalizedSearchTerm)
    );
    // ✅ Intl.Collator 提升排序性能
    const collator = new Intl.Collator('zh-CN');
    return filtered.sort((a, b) => { ... });
  }, [users, normalizedSearchTerm, sortField]);
  
  // ✅ useDeferredValue 优化输入响应
  const deferredUsers = useDeferredValue(processedUsers);
  
  return ( ... );
}

反模式：WebSocket 内存泄漏

function ChatRoom({ roomId }) {
  useEffect(() => {
    const ws = new WebSocket(`wss://api.example.com/chat/${roomId}`);
    ws.onmessage = (event) => {
      setMessages(prev => [...prev, JSON.parse(event.data)]);
    };
    // 🔴 没有清理函数！连接永不关闭
    // 🔴 roomId 变化时旧连接未关闭
  }, [roomId]);
}

⚠️ 后果：组件卸载后连接存活、roomId变化时多个连接同时存在

✅ 修复：cleanup 函数

useEffect(() => {
  let isMounted = true;
  let reconnectTimer = null;
  
  const connect = () => {
    const ws = new WebSocket(`wss://api.example.com/chat/${roomId}`);
    wsRef.current = ws;
    
    ws.onclose = () => {
      if (isMounted) reconnectTimer = setTimeout(connect, 3000);
    };
  };
  
  connect();
  
  // ✅ 清理：关闭连接、取消重连
  return () => {
    isMounted = false;
    clearTimeout(reconnectTimer);
    if (wsRef.current?.readyState === WebSocket.OPEN) {
      wsRef.current.close();
    }
  };
}, [roomId]);

📚 今日模式库更新

🔴 新增反模式

  • 渲染内重复计算
    循环/filter/sort在render内
  • 资源未清理泄漏
    useEffect无return
  • 状态闭包捕获
    闭包持有旧state引用

✅ 新增设计模式

  • 协议依赖注入
    Mock测试必备
  • 响应式自动取消
    cancellables.store
  • 副作用清理
    资源管理基础

🤖 AI生成代码的常见隐瞒点

1️⃣ 性能优化

不提 useMemo / useCallback / 虚拟列表

2️⃣ 资源清理

不提 cleanup 函数 / unsubscribe

3️⃣ 边界条件

不提空值处理 / 超长数据 / 并发问题

💡 关键发现总结

跨语言通用智慧

  1. 资源获取必有释放
  2. 计算结果尽量缓存
  3. 依赖变化要追踪

架构设计原则

  1. 单一职责 > 过度抽象
  2. 显式优于隐式
  3. 可测试性驱动设计
